# Simple Interest Calculator

This project contains a Bash script that calculates simple interest from three user inputs: principal amount, annual rate of interest, and time period in years.

## Formula

The calculator uses the simple-interest formula:

```text
simple interest = principal x rate x time / 100
```

It also displays the total amount, calculated as the principal plus the simple interest.

## Usage

Run the script from a Bash terminal:

```bash
bash simple-interest.sh
```

When prompted, enter the principal amount, annual interest rate as a percentage, and time period in years.
